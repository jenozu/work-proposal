# Invoice Retrieval

**Group:** Finance  
**Working stage:** previously prototyped; verify current deployment and permissions. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Employees search inboxes and folders to find supplier invoices for colleagues.

## Proposed improvement
Search approved document and mailbox sources by invoice number/vendor/PO and return matching files.

## Testable measures
Time per search; requests per month; false matches; access-control compliance.

## External possibility
Document-retrieval implementation or managed subscription.

## Boundaries and open questions
Restrict sources and permissions; do not expose unrestricted mailboxes.

## Financial note
See [[Invoice Retrieval - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
