# Inventory cycle counting — Source workbooks

This folder is for unchanged SAP export workbooks used by the cycle-counting pilot. Source files can be reviewed alongside the existing [Inventory Counting overview](../Inventory%20Counting%20-%20Overview.md) and [Working CBA](../Inventory%20Counting%20-%20Working%20CBA.md).

| File | Intended purpose |
|---|---|
| `05_Inventory_Movements_60M.xlsx` | Inventory movement history |
| `06_Sales_Delivery_60M.xlsx` | Sales and delivery transaction history |
| `07_Purchasing_Receiving_60M.xlsx` | Purchasing and receiving history |
| `08_Bin_Locations_Inventory.xlsx` | Bin locations and quantity-on-hand data |
| `09_Historical_Inventory_Counts_60M.xlsx` | Historic count records |
| `master_inventory.xlsx` | Combined cycle-counting analysis workbook |

For reproducibility, retain the spreadsheet originals as `.xlsx`, not CSV, and do not overwrite them with analysis outputs. Temporary upload suffixes such as `(3)` should be removed from the committed filenames.

**Status:** The folder names and manifest are in place. The original spreadsheets have not yet been uploaded. This repository is public; review the data before publication.
