# Inventory Counting

**Group:** Warehouse  
**Working stage:** existing RF capabilities targeted for validation. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Paper/spreadsheet counts and variance follow-up use employee time and can obscure discrepancies.

## Proposed improvement
Mobile cycle, area and full-count workflows with review and adjustment reporting.

## Testable measures
Count preparation and execution time; variance follow-up time; recounts; adjustment error rate.

## External possibility
Standalone mobile cycle-counting application or WMS module.

## Boundaries and open questions
Avoid double-counting savings attributed to RF Scanner.

## Financial note
See [[Inventory Counting - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
