# SAP Operations Companion

**Group:** ERP  
**Working stage:** concept inspired by existing workflow tools. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Some employees navigate many SAP screens for small recurring pieces of information.

## Proposed improvement
Approved lightweight views for orders, inventory, bins, shipments and document status.

## Testable measures
Minutes per lookup; SAP exports avoided; query accuracy; user adoption.

## External possibility
Configurable ERP companion with installation and maintenance.

## Boundaries and open questions
Use supported SAP Business One access; no assumption of direct SQL availability.

## Financial note
See [[SAP Operations Companion - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
