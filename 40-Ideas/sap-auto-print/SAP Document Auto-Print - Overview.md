# SAP Document Auto-Print

**Group:** ERP  
**Working stage:** configuration/automation idea. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Employees manually print certain SAP documents after creating them.

## Proposed improvement
Evaluate supported automatic printing for landed costs, goods receipts and deliveries.

## Testable measures
Clicks/minutes per document; print failures; maintenance.

## External possibility
Likely configuration service, not a standalone SaaS product.

## Boundaries and open questions
Check native SAP capabilities first; do not build custom software unnecessarily.

## Financial note
See [[SAP Document Auto-Print - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
