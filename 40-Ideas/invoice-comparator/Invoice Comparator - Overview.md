# Invoice / PO / GRPO Comparator

**Group:** Finance  
**Working stage:** previously developed tool; verify current deployment. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Employees manually compare large invoices against purchasing and receiving documents.

## Proposed improvement
Identify mismatched prices, quantities, missing lines and exceptions using structured imports and invoice information.

## Testable measures
Minutes per document; exception accuracy; discrepancies detected; rework avoided.

## External possibility
Subscription tool or custom integration for distributors and accounts-payable teams.

## Boundaries and open questions
Test against verified documents; human review remains required before posting.

## Financial note
See [[Invoice Comparator - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
