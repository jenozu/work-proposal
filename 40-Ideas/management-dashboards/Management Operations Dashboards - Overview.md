# Management Operations Dashboards

**Group:** Analytics  
**Working stage:** concept. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Department metrics require manual exports and assembly across systems.

## Proposed improvement
Present agreed operational KPIs in a concise management dashboard.

## Testable measures
Report preparation time; data freshness; exception response time.

## External possibility
Custom dashboard implementation and support.

## Boundaries and open questions
Define each KPI and the authoritative source before building.

## Financial note
See [[Management Operations Dashboards - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
