# GRPO Document Attachment

**Group:** ERP  
**Working stage:** concept. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Supporting documents may require manual attachment to SAP goods-receipt records.

## Proposed improvement
Match authorized source files to GRPO references and attach via supported integration if available.

## Testable measures
Minutes per attachment; retrieval time; incorrect/missing attachments.

## External possibility
Implementation-specific SAP add-on.

## Boundaries and open questions
Confirm API entitlements, attachments access and permissions.

See [[GRPO Document Attachment - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
