# RF Scanner / Lightweight WMS

**Group:** Warehouse  
**Working stage:** existing development project; validate current features against live code. This is a proposal status, not a verification of the current code/deployment.

## Current inefficiency
Separate warehouse steps, repeated lookups and travel, inconsistent movement visibility.

## Proposed improvement
A mobile warehouse tool supporting item/bin inquiry, receiving, putaway, guided picking, wave picking, staging, counting and movement history.

## Testable measures
Lookup time; complete pick time including sorting; receiving/putaway time; count time; errors and corrections; adoption.

## External possibility
Configurable warehouse management software with possible onboarding and recurring licences.

## Boundaries and open questions
Treat the linked RF Scanner implementation repository as the source of truth. Some features remain planned, and direct SAP posting is not assumed.

## Financial note
See [[RF Scanner - Working CBA]] for the project-specific financial evidence checklist. Before proceeding, identify workflow owner, frequency, existing cost, initial investment and operational dependencies.
