# RF Scanner — Pilot Test Plan

Objective: obtain fair before-and-after evidence during the [[60-Day Pilot Plan]], not merely a successful demonstration.

## Test groups
1. Time 15–30 real item/bin lookups before and after.
2. Pick comparable 3-, 5- and 10-order batches through the full completion workflow; count routing plus final sorting.
3. Time representative receiving **and** putaway tasks.
4. Time comparable cycle-count sets, including variance follow-up.
5. Log errors, rework, adoption and failures in all groups.

Record task date, number of lines/units, employee, workflow method, start/finish time, sorting time (picking), corrections, abnormal conditions, and any reasons to exclude a run. Include setup time if routine.

## Comparison
Report medians and ranges alongside means where sample size permits. Scale only representative volumes to an annual run rate. Test whether speed improvements introduce quality trade-offs.

## Gate
A working tool is not the same as a measured financial improvement. At day 60, update [[RF Scanner - Detailed CBA]] and explain uncertainty.
