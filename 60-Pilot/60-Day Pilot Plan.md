# 60-Day Operations Improvement Pilot

**Goal:** verify a small number of operational improvements and produce management-ready cost-benefit analyses, not finish the entire idea portfolio.

| Period | Work | Evidence |
|---|---|---|
| Days 1–10 | Agree test workflows and collect baseline volumes/timings | Dated baseline log, sampling rules |
| Days 11–30 | Stabilize selected prototypes; check data, training and safety | Scope, test records, known limitations |
| Days 31–45 | Conduct representative before/after tests with employees | Complete trials, errors, feedback |
| Days 46–60 | Update costs and business cases; review commercialization fit | Short and detailed CBAs, status and decision report |

Initial candidate: [[RF Scanner - Pilot Test Plan]]. Add other tools only when selected with management and realistically testable within the same 60 days.

**Day-60 delivery:** updated [[Executive Portfolio Summary]], measured project CBA(s), screenshots using only authorized/anonymized data, risk register, recommended next-stage work and a separate external opportunity assessment.

A result can be neutral or negative; report it rather than retrofitting assumptions.
